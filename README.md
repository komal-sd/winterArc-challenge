# ❄️ DevOps Winter Arc — 90 Days Challenge

A hands-on learning journey covering Linux, Git, Docker, CI/CD,
AWS, Terraform, Kubernetes, monitoring, and DevOps practices.

## Goals

- Strengthen Linux and DevOps fundamentals.
- Build practical projects.
- Practice troubleshooting and document root causes.
- Learn automation and infrastructure as code.
- Prepare for DevOps interviews and the CKA certification.
- Maintain evidence of completed work.

## Repository Structure

- `progress/` — Daily and weekly progress tracking.
- `daily-challenges/` — Work organized by challenge day and week.
- `projects/` — Practical DevOps projects.
- `scripts/` — Bash and Python automation.
- `troubleshooting/` — Incidents, investigations, and fixes.
- `docs/` — Interview notes and architecture documentation.
- `evidence/` — Relevant screenshots and supporting evidence.

## Daily Learning Record

For each challenge, document:

1. Goal
2. Concepts learned
3. Hands-on work
4. Verification and evidence
5. Problems encountered and fixes
6. Key takeaways
7. Pending work

## Learning Approach

Learn → Practice → Build → Troubleshoot → Verify → Document

Only verified work is marked complete.
