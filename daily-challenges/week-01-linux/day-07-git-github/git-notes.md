# Day 7 — Git Learning Notes

## Commands Practised

| Command | Purpose |
|---|---|
| git --version | Check the installed Git version |
| git config --global --list | Inspect global Git configuration |
| git init | Initialize a local repository |
| git status | Inspect working tree status |
| git add | Stage changes |
| git commit | Record staged changes |
| git log --oneline | View concise commit history |
| git switch -c | Create and switch to a branch |
| git branch | List local branches |
